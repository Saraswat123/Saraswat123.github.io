R&D Agent: user flow

WhatsApp report in, a gateway reads it, a language step structures it, the Sheet API writes the daily log, the STEM agent reviews Drive and the curriculum sheet against it, a cross-check verifies, the sheet is updated, and a scoring matrix closes the loop.
