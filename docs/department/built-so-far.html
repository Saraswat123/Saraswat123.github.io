Meeting-minutes agent: flow

Transcript in, validated minutes and one sheet row out. It runs as a dry run unless told to send, and the model gets no tools.

flowchart TD
    A["Meeting recording or transcript<br/>VTT, SRT, text or JSON export"] --> B["Read and clean<br/>strip timestamps, size limit"]
    B --> C["Claude Code headless<br/>subscription, no tools, no API key"]
    C --> D{"Validate JSON<br/>schema and length caps"}
    D -->|ok| E["Minutes file<br/>summary, decisions, action items, risks"]
    D -->|bad| F["Reject, nothing written"]
    E --> G["Build sheet row<br/>formula-safe cells"]
    G --> H{"Dry run?"}
    H -->|default| I["Print the row, send nothing"]
    H -->|send flag| J["Apps Script web app<br/>secret token checked"]
    J --> K["Meetings sheet"]
