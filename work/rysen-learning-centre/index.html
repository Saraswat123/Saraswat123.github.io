Rysen Learning Centre

← /work

End-to-end LMS and operations tool for an edtech group

Rysen Learning Centre is an end-to-end LMS and operations tool: onboarding, staged training and testing, automatic certification, live task tracking, monitoring dashboards and message delivery for every educator, principal and student in one place. Rysen AI, an agent built into it, runs admin work in plain language.

Planned, built and deployed the platform from scratch, wrote its design and test documents, and trained the users.

Live platform with two role-scoped AI agents; model configuration verified in the current application source.

Engineering and delivery

Model and tool calling

The current application source configures openai/gpt-oss-120b through Groq for both admin and educator agents. The model requests tools; application code executes them against live platform data and returns the results.

Execution limits and recovery

The admin agent limits a request to eight model steps and 2,000 output tokens per completion. Malformed tool-call generation is retried once with the same tool definitions. Tool errors are returned to the loop, and the response includes the actions attempted.

Application and deployment

Next.js and TypeScript provide the application, Prisma connects to Neon Postgres, and Vercel hosts the platform. Model inference is accessed through the Groq API. Educator tools are scoped to the signed-in educator and campus.

Delivery and evaluation

I owned planning, implementation, deployment and user training. The documented suite has 78 automated tests with CI on pushes; this is software test coverage, not a measured production task-success rate.

What it covers, end to end

Onboarding

New accounts get a welcome email, then an OTP-verified first login that sets the password. Bulk import for educators and students.

Training

Staged programmes with MCQ stages, pass thresholds and attempt caps. Educators enrol themselves and track their progress.

Testing

Student tests with scheduled windows, a different question order per student, one attempt per test and instant scores.

Certification

E-certificates unlock automatically when every stage of a programme is passed. Nobody has to notice or send them.

Live tracking

Tasks with subtasks, assignments, comments and a full history timeline for each task.

Monitoring

Campus pass-rate reports, class analytics with dropout funnel and at-risk lists, and a weekly digest email to admins.

Review

Monthly recognition: star ratings by category, AI-suggested scores from real data, finalise and lock, top-3 certificates.

Message delivery

Email and WhatsApp broadcasts, reminders, group chat and in-app notifications.

Rysen AI

Admin agent

16 tools: create, update and assign tasks, manage educator groups, add subtasks and resources, send reminders and pull real test-completion numbers. Capped at 8 steps per request.

Educator agent

7 tools: my tasks, task details, mark a subtask complete, my resources, my students' tests and progress, my recognition.

Outcome

Admins manage tasks and follow-ups in plain language, with answers drawn from live data instead of guesses.
