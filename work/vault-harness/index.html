Vault Harness

← /work

Guarded payments for AI agents

A payment harness that lets an AI agent pay online without ever seeing, storing or remembering a card number. The card is sealed in the owner's browser and only exists in clear inside an isolated enclave, for one payment. Letting an agent pay is a credential-isolation problem before it is an AI problem, so the isolation is enforced by code and a hardware boundary, not by asking the model nicely.

Solo design and build, October to November 2026.

Status: 7 real payments confirmed on the card statement. The AWS Nitro enclave is prepared and tested against synthetic documents, not yet run on AWS. Touch ID approval is tested with a software authenticator. The repository is private.

Trust zones

Agent

Holds the task text and a JSON proposal. It has no tool that reaches a card field or a key.

Harness host

Holds ciphertext, placeholders and masked results only. Never the card in clear, never a CVC at rest.

Cloud browser

A stateless browser with no profile. It sees a one-time placeholder card, never the real one.

Enclave

The only place the real card exists in clear, in memory, for one payment. Then it forgets.

The guard, before any payment

1. Freeze check

A frozen card or agent is refused at once. Freezing never needs a fingerprint.

2. Policy

Per-purchase cap, merchant and currency allowlist, strict schema. Unknown fields are rejected.

3. Velocity

Payments and spend per minute, hour and day, checked on the host and re-reserved inside the enclave.

4. Risk score

Scored against the median of the last 200 payments. Above a threshold it escalates to a human.

5. Human approval

Touch ID above the auto-approve limit, verified inside the enclave, not by the host.

6. Post-check

The charged amount must equal the approved amount, or the run halts and alerts.

Stated gaps

Enclave not on AWS yet

It is a separate program and a Docker image. The Nitro build, attestation and KMS plan are written and tested only against synthetic documents.

Counters live in enclave memory

A host that can restart the enclave resets budget and velocity. Rollback-proof sealed counters are not built.

Software authenticator

Touch ID is tested against a software authenticator, not yet a real device.

CVC is the scaling limit

Stripe and PCI DSS forbid storing one. A processor or network token is the next step and is not built.

Local agent API

It is unauthenticated, safe only because the host is trusted. Production needs a separate, authenticated agent identity.
